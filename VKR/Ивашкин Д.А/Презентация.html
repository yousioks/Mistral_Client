Защищаемый объект и активы

Корпоративный веб-портал

Сайт ООО «Ремон Девелопер» — критическая бизнес-единица компании. Установлен на выделенном сервере под управлением ОС Ubuntu 24.

Критические требования

Обеспечение непрерывной доступности сайта для внешних пользователей. Простой портала ведет к прямым финансовым потерям.

Фрагментация логов

Системные журналы веб-сервера Ubuntu 24, БД и ОС собираются разрозненно. Единая точка сбора телеметрии отсутствует.

Реактивный подход

Критически долгое время реакции. При Brute-Force или SQLi специалист вынужден вручную сопоставлять данные для блокировки.

Уязвимости в коде

Внедрение новых функций на портал происходит без автоматизированных систем контроля SAST/SCA.

Дефицит кадров

В штате распределенной компании всего 1 специалист. Ручной мониторинг физически невозможен.

Разрабатываемые решения

1. Mistral Server (Ядро)

Координирующий бэкенд (Lua-скрипты). Хранит логи в SQLite, применяет SOAR и API LLM.

Node.js / Express / SQLite

2. Mistral Client

Десктопное приложение. Отображает инциденты, строит карту угроз и позволяет управлять блокировками.

Electron.js / HTML5 Canvas

Защита доступа и WSS

Взаимодействие между сервером и Mistral Client осуществляется по полнодуплексному протоколу WebSocket Secure (WSS) поверх TLS, что исключает избыточный HTTP-Polling.

  • Аутентификация API

    Генерация сессионного токена при входе.

  • Защита от Replay Attack

    Проверка одноразового nonce-идентификатора.

  • Изоляция Electron

    Внедрение contextIsolation и безопасного IPC-моста.

Уровень ядра: Автоматизация (SOAR)

Динамическое экранирование

Система анализирует логи. При фиксации перебора SSH или сетевого флуда, ядро SOAR формирует правило ufw deny, изолируя IP-адрес без участия оператора.

Режим активного мониторинга

Система непрерывно собирает телеметрию. Встроенные системные логи, метрики контейнеров и предупреждения об угрозах (DDoS, аномальные процессы) консолидируются в едином рабочем пространстве Mistral Client.

DevSecOps (Аудит кода)

Semgrep (SAST)

Инструмент статического анализа кода портала. Выявляет уязвимости (SQL-инъекции, хардкод паролей) до вывода в продакшен.

Trivy (SCA)

Сканер зависимостей. Сопоставляет версии библиотек npm и пакетов ОС Ubuntu с международными базами уязвимостей CVE.

Интеллектуальный ИИ-Агент

Авторасследование инцидентов

Сервер интегрирован с языковыми моделями через защищенный API-шлюз. Агент получает на вход сырые логи уязвимостей, семантически разбирает их и генерирует готовые патчи (bash-скрипты).

Это позволяет оператору в один клик ликвидировать сложные угрозы, заменяя часы ручного разбора кода и конфигураций.
