# Дипломный проект: MISTRAL Defense & Remon

Данный репозиторий содержит полный исходный код дипломного проекта по информационной безопасности. Проект состоит из четырёх основных компонентов, демонстрирующих современные методы защиты веб-приложений и инфраструктуры с использованием ИИ.

## Компоненты

1. **Remon** (`/Remon`)
   - Учебное веб-приложение (сайт девелоперской компании) с намеренными уязвимостями.
   - Написано на Next.js (Frontend) и Express (Backend).
   - Включает админ-панель с функцией **Глобальных Медиа** (динамическое управление баннерами на всех страницах).
2. **Mistral Server** (`/Mistral Server`)
   - Сервер безопасности (REST API + WSS), собирающий логи, алерты и инциденты.
   - Встроенный Telegram-бот с красивым HTML-дизайном и кнопкой **[ 🧠 АНАЛИЗ ИИ ]** для мгновенной реакции.
3. **Mistral Client** (`/Mistral Сlient`)
   - Десктопное приложение для оператора ИБ (Electron).
   - Красивый UI, графики в реальном времени, возможность изоляции опасных блоков кода.
   - Скомпилировано в Portable `.exe` версию.
4. **Mistral Demo** (`/Mistral Demo`)
   - Презентационный Python-скрипт `attack_simulator.py` (с лаунчером `start_demo.bat`).
   - Медленно симулирует Nmap-сканирование, SSH брутфорс и SQL-инъекцию для наглядной демонстрации работы защиты.

## Быстрый старт для демонстрации

1. Запустить Remon (через Docker Compose).
2. Запустить `Mistral Server/start.sh`.
3. Открыть скомпилированный `MISTRAL-Defense-Portable-1.1.0.exe`.
4. Запустить `Mistral Demo/start_demo.bat` и наблюдать за реакцией системы защиты в клиенте и в Telegram!
